# LeetCode 刷题计划（示其版）

> 整理日期：2026.8.8
> 定位：配合 Python 50 天计划，按当前水平筛选的刷题清单，不绑定具体某一天，坚持每日一题、有空加练。
> 题号以 LeetCode 官网为准，直接在官网或中文站搜索题号即可。

---

## 一、筛选依据

- 当前已学：Day 1-13（四大容器、字符串、函数、文件、异常、正则）
- 后续会继续学语法深水区和算法基础，题目难度与知识点已按当前水平排好顺序
- 现阶段适合：Easy 为主，少量 Medium；重点覆盖数组、字符串、哈希、双指针、二分、栈、简单递归
- 参考仓库：代码随想录 leetcode-master、Hello 算法、leetcode-patterns、TheAlgorithms/Python

## 二、刷题原则

1. 坚持每日一题，时间充裕可以加练到 2-3 题，不图快
2. 先独立思考 15-20 分钟，没思路再看题解
3. 每题记下：用了什么数据结构、思路、时间/空间复杂度、能不能优化
4. 现阶段用 Python 刷；大一再挑经典题用 C++ 重写一遍（408 机试/竞赛也用）
5. 按分组顺序推进，不绑定具体某一天，有空就刷，保持手感

## 八、使用方式

- 在项目里新建 `LeetCode/` 文件夹，每道题一个 `.py` 文件，命名格式：`题号_题名.py`
- 做完一题在文件顶部注释里写：思路、复杂度、踩坑点
- 每日一题：固定选一个自己方便的时间，每天完成 1 题；当天状态好就追加
- 每完成一批，在 Python 学习日志里记录一次进度
