# 转专业到人工智能 · 计划

> 示其 · 数学与应用数学 → 两江人工智能学院「人工智能」专业
> 整理：2026.9.4 ｜ 依据：学校《转专业管理暂行办法》(重理工发〔2020〕5号) + 两江人工智能学院 2024 转专业工作方案

---

## 一、目标

**大一上结束申请，从数学与应用数学转入「人工智能」专业。** 大一下进入 AI 专业学习。

## 二、转专业资格核对（闸门）

| 项 | 要求 | 你的情况 |
|----|------|---------|
| 高考物理 | 高考成绩需含物理科目 | ✅ 已确认（高考选考物理） |
| 学满一学期 | 校规第七条第(一)款 | 大一上结束自然满足 |
| 身份 | 普通全日制、非特殊招生、未转过一次 | ✅ 适用 |
| 英语 | 先修课及格 | 大学英语1，需及格 |
| 程序设计及实践 | 先修课及格 | 《程序设计及实践[C语言版]》第4-11周，需及格 |
| 高等数学 | 无则豁免 | 数学专业是数学分析 → **豁免** |
| 大学计算机 | 无则豁免 | 已确认无碍，按大一上转规划 |
| 程序设计基础 | 无则豁免 | 同上 |

> ✅ **2026.9.4 确认**：按"大一上结束转专业"推进，资格条件均已满足，后续按此规划执行。

## 三、评分（决定性）

> **综合成绩 = 面试考核分 × 30% + 平均学分绩点 × 70%**

**GPA 占 70%**，面试占 30%。名额紧张（原则不超该专业年级人数 10%，热门可能 ≤5%），全靠绩点刷人。

## 四、节奏安排

| 时间 | 动作 |
|------|------|
| 第1学期 | 刷高 GPA；程序设计及实践、英语及格；Python + 小项目 |
| 第1学期末 | 满足"学满一学期"，盯学院转专业通知，卡窗口申请 |
| 大一下 | 转入 AI 专业，缺的课按学分认定/补修处理 |

## 五、本学期重点（不做 AI 课表预习）

| 优先级 | 内容 | 为什么 |
|-------|------|-------|
| 高 | 数学专业课（数分/高代/解几）考高 | GPA 占 70% |
| 高 | 程序设计及实践[C语言版]、英语及格 | 先修课 |
| 中 | 一个 AI 小项目 | 专长证明 + 面试演示 |
| 中 | Python / 算法(LeetCode) | 计算思维 + 兴趣证据 |
| 低 | 数学竞赛（可能参加不了，非必需） | "如获奖证书"非硬性 |
| 不做 | AI 专业课预习 | 无地基、不计分、抢时间 |

## 六、面试准备

- **3 分钟陈述**：为什么转(数学人+真心 AI) → 我有什么基础(Python/小项目) → 现在学得如何 → 转进来怎么学
- **核心打法**：数学是 AI 的底层(线性代数+概率+优化)，你的数学分析/高代就是地基 → 和"跟风转专业的"划清界限
- **计算思维题**：拆解→数据结构→步骤→效率（用 Python/算法自学的实例回答）
- **材料**：高考物理证明、成绩单(签字盖章)、兴趣/专长证明(Python/AI 小项目)、申请表(只填一个志愿)

## 七、转后注意事项

- 转专业后按 AI 专业培养方案执行；已修合格课程符合要求可认定学分，不足补修
- 你的数学分析/高代比 AI 的"高等数学"更强，大概率直接认定；AI 有而你没有的多是低阶课(技能训练/课程设计)，补修轻松
