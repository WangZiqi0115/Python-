# Day 2 · 文件系统与路径(pwd / ls / cd / 绝对 vs 相对)(2026.9.5)
====================================================
今天搞懂三件事:
1. Linux 的"文件系统"是一棵什么树
2. 怎么用 pwd / ls / cd 在这棵树上移动
3. 绝对路径 vs 相对路径 —— 这是新手最容易绕晕、但最核心的概念


# 一、Linux 的一切都是"文件"

先记住 Linux 的一句名言:**"一切皆文件"(Everything is a file)**。
- 你的文档 → 文件
- 你的程序 → 文件
- 你的目录(文件夹)→ 一种特殊的文件
- 你的硬盘、甚至你插的 U 盘 → 也是文件(挂载点)

**给数学系的一个类比(可跳过):**
文件系统就像一棵**树**。根目录 ` / ` 是树根,下面分出一个个目录(树枝),目录里再放文件(树叶)。
你在 Linux 里做的事情,99% 就是**在这棵树上找路、挪东西**。所以今天这节是后面所有操作的地基。

> 记住这棵树的顶部叫 ` / `(根目录),它是整棵树的起点。所有路径都从它出发。

# 二、三个最常用的导航命令

上节学了 `pwd` `ls` `clear`,今天加一个 `cd`,并把它讲透。

```bash
pwd         # 我在哪?打印当前所在的"绝对路径"
ls          # 这里有什么?列出当前目录的内容
cd  目标    # 去哪里?切换到另一个目录 (Change Directory)
```

**cd 的几种用法:**
```bash
cd           # 不加参数 = 回到"家目录"~ (个人文件夹)
cd 某目录    # 进入某个目录
cd ..       # 回到上一级目录(.. 是"上一级"的代号)
cd .        # 留原地(. 是"当前目录"的代号,通常用不到)
cd -        # 回到上一次所在的目录(方便来回切换)
cd /        # 直接跳到根目录
```

**小口诀:** `cd` 后面跟"你想去的地方"。`.` 代表当前,`..` 代表上一级,`~` 代表家。

# 三、绝对路径 vs 相对路径(今天的重点)

这是新手最易晕的地方,用一个比喻讲清:

**绝对路径 = 从"树根"开始写的完整地址。**
- 一定以 `/` 开头
- 例:`/home/shiq/文档`
- 就像快递地址写全:"中国 重庆 重庆理工大学 某某楼"
- **不管你在哪,绝对路径指向同一个地方**,永远唯一。

**相对路径 = 从"你现在的位置"开始写的地址。**
- **不以 `/` 开头**
- 例:你已经在 `/home/shiq`,想进 `文档`,直接写 `cd 文档` 即可
- 就像朋友问路:"往前走两条街左转"——**相对位置,取决于你现在在哪**
- 换了个位置,同一个相对路径可能指向不同的地方。

**给数学系的类比:**
绝对路径像**坐标系里的绝对坐标**,相对路径像**"向量"**——delta,相对某个参考点才有意义。你站的地方(参考点)变了,同一个相对位移就到不同地方。

# 四、几个常用符号(路径里的"暗号")

| 符号 | 含义 | 例子 |
|------|------|------|
| `/` | 根目录 | `cd /` |
| `~` | 家目录(你的个人地盘) | `cd ~` |
| `.` | 当前目录 | `./run.sh`(运行当前目录下的脚本)|
| `..` | 上一级目录 | `cd ..` |
| `-` | 上一次所在的目录 | `cd -` |

> 注意:`~` 和 `/` 很像但不是一回事。`~` 是"你个人文件夹"的缩写,`/` 是"整个系统最顶层"。`~` = `/home/你的用户名`。

# 五、今天的小总结 · 你已经会的事

1. 知道 Linux 是"一棵文件树",根是 `/`
2. 用 `pwd` 看自己在哪、用 `ls` 看有什么、用 `cd` 去别处
3. 分清**绝对路径**(以 `/` 开头,永远固定)和**相对路径**(不带 `/`,随位置变)
4. 看懂 `~` `.` `..` `-` 这几个"暗号"

# 六、一个小练习预告(去练习文件做)

在终端里敲这几条,观察路径的变化:
```bash
pwd                 # 现在在哪?
cd /                # 跳到根目录
pwd                 # 在哪了?
ls                  # 根目录下有什么?
cd /home            # 进 home
pwd
ls
cd ..              # 回上一级
pwd
```
做完你会发现 `pwd` 每次都告诉你真实的当前位置——这就是"绝对路径"。
