# Day 2 · 练习 (2026.9.5)
====================================
今天主题:文件系统与路径。在 Ubuntu 终端里照着敲,敲错没关系,重点是**观察 pwd 的变化**——它就是你的"定位仪"。

## 练习 1 · 认识 home(2 分钟)
```bash
pwd          # 记下你现在在哪(应该在 /home/用户名 或 ~)
ls           # 看看这里有什么
echo ~       # 看看 ~ 展开成什么(就是你 home 的完整路径)
cd           # 不带参数,直接回车
pwd          # 是不是回到了 home?
```

## 练习 2 · 用绝对路径到处跑(3 分钟)
```bash
cd /         # 跳到根目录
pwd          # 应该显示 /
ls           # 根目录下有一堆目录(usr、home、etc、tmp...)
cd /home     # 进 home
pwd
ls
```
> 思考:`/` 和 `/home` 都是绝对路径(以 `/` 开头)。`pwd` 应该一路跟着变。

## 练习 3 · 用相对路径 + .. 来回走(3 分钟)
```bash
cd /home            # 先站到 /home
cd ..               # 往上退一级
pwd                 # 回到 / 了吗?
cd home             # 注意:这个不带 /,是相对路径
pwd                 # 你又回到 /home 了
ls ..
```
> 思考:为什么 `cd home`(相对)能成功?因为你此刻正在 `/`,下面就有 `home`。这就是"相对路径取决于你现在的位子"。

## 练习 4 · 区分绝对/相对(3 分钟)
靠"**开头有没有 `/`**"判断。下面每条,心里先说出它是<绝对>还是<相对>:
```bash
cd /etc                  # 绝对?相对?
cd etc                   # 这个会成功吗?为什么?留意报错
cd ~/                    # 到哪?
cd ..                    # 哪?
cd ../..                 # 连退两级,现在在哪?
```
> 提示:`cd etc` 大概率报错"没有那个目录",因为你不在 `/`,当前目录下没有 `etc`——**这就是相对路径和位置的依赖**。
