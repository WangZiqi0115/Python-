# 一、为什么你得学 Linux

你是数学专业，想去计算机的 AI 方向，又对网安感兴趣。这两条路，Linux 都是绕不开的**共同地基**。

**AI 方向为什么需要 Linux**
- 所有大模型的训练都是在 Linux 服务器上跑的
- 显卡驱动、CUDA、深度学习框架（PyTorch / TensorFlow）都是命令行生态
- Docker 容器、云服务器（阿里云 / AWS）、跑模型的机器 —— 全是命令行
- 一句话：AI 工程师的工作终端，大概率就是 Linux

**网安方向为什么需要 Linux**
- 渗透测试的行业标准平台是 Kali Linux（基于 Debian，和你的 Ubuntu 是亲戚）
- 网安核心工具几乎全是 Linux 命令行工具：nmap、sqlmap、metasploit、wireshark
- 想玩网安，命令行是基本功

**数学 → 计算机的「系统课」**
- 数学训练你抽象和严格推理；计算机要你理解「东西怎么在机器上跑」
- Linux 是唯一完全开放、透明、你能看穿的系统
- 把 Linux 搞懂，你就摸到了「操作系统」这门课的门

> 一句话总结：学 Linux，等于同时给「AI」和「网安」两块地基打桩。


# 二、虚拟机是什么

你刚在电脑上装的，是一个**虚拟机里的 Ubuntu**。

**比喻：一台真实电脑上，用软件「变」出另一台电脑**
- 你的这台 Windows 电脑叫**宿主机（host）** —— 真正的硬件
- 里面跑的 Ubuntu 叫**客户机（guest）** 或**虚拟机** —— 是软件模拟出来的
- 用什么模拟？你装的那个软件就是「虚拟机软件」（VMware / VirtualBox / Hyper-V 等）

**虚拟机的好处（对你来说超重要）**
- **随便折腾，不怕弄坏** —— 这是最珍贵的特性
- Ubuntu 是一个「沙盒」，你可以在里面随便乱试命令
- 搞坏了怎么办？**拍快照（Snapshot）**：动手前拍一张，坏了一键还原回到那一刻
- 以后学网安，很多操作都要在虚拟机里做，就因为它隔离、安全、可还原

> 记住：命令行世界不怕犯错，怕的是不敢试。虚拟机给了你试错的底气。


# 三、认识 Ubuntu

你装的是 **Ubuntu**，最有名的桌面 Linux 发行版之一，基于 Debian。
- 界面友好、资料最多、新手首选
- 和网安常用的 Kali 是近亲，后面学的东西基本通用


# 四、打开终端（Terminal）

图形界面用鼠标点；但对系统玩得深的人，最有效率的方式是**终端** —— 用文字跟系统对话。

**怎么打开：**
- 快捷键：`Ctrl + Alt + T`
- 或者点左上角的「Activities / 活动」，搜 `terminal` / `终端`

打开后你会看到类似这样一行（这就是**提示符**）：

```
shiq@ubuntu: ~$
```

拆开看：
- `shiq` = 当前用户名
- `ubuntu` = 这台机器的名字（主机名）
- `~` = 当前所在目录；`~` 是「家目录」的缩写（每个人默认存东西的地方）
- `$` = 你现在是普通用户；如果是 `#`，说明是超级管理员（root）


# 五、人生第一批命令

命令就是「让系统干活的一句话」。下面这几个最基础也最常见。**在终端里一个个敲，每行敲完按回车。**

```bash
whoami      # 我是谁？显示当前用户名
pwd         # 我在哪？（Print Working Directory）显示当前完整路径
ls          # 这里有什么？（List）列出当前目录下的文件
clear       # 清屏，让屏幕清爽一点
```

**术语小课堂：**
- 命令后的 `#` 是**注释**，系统会忽略它，只是写给你看的
- 命令 = 动词（你想让系统做什么），后面常跟一个「对象」（比如 `ls` 后面加个路径）

**给数学系的一个类比（可跳过）：**
- 命令像函数：`ls` 就是「输入一个目录 → 输出文件清单」
- 管道（后面会学）就像复合函数：小命令用 `|` 串成一个大操作，很像函数套函数


# 六、今日小结 · 你现在已经会的事

1. 打开终端
2. 读提示符（用户名 / 主机名 / 路径 / `$` 还是 `#`）
3. 用 `whoami`、`pwd`、`ls`、`clear` 四个命令跟系统对话
4. 知道 Linux 对 AI 和网安有多重要 —— 这是你学它的动力


# 七、动手前：先拍个快照！

开始努力之前，给你的虚拟机拍一张**快照（Snapshot）**：
- 找虚拟机软件菜单里的「快照 / Snapshot」，拍一张「初始状态」
- 以后无论敲错命令、装坏系统，都能一键还原回来
- 这是你在虚拟机里混的「安全网」，以后每次动手前都可以拍
