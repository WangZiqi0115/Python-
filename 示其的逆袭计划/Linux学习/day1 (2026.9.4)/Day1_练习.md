# Day 1 · 练习 (2026.9.4)
====================================
不用动脑子，就是让你的手指先熟起来。在 Ubuntu 终端里照着敲，敲错完全没关系。

## 练习 1 · 认识提示符（1 分钟）
1. 打开终端（`Ctrl + Alt + T`）
2. 看提示符，说出：你的**用户名**是什么？**主机名**是什么？现在**在哪**（`~` 还是别的）？

## 练习 2 · 四个基础命令（5 分钟）
依次敲，观察每个命令的回应：
```bash
whoami
pwd
ls
clear
```
想一想：
- `whoami` 输出的名字，和提示符里的一样吗？
- `pwd` 输出的路径，是不是以你用户名命名的文件夹结尾？
- `ls` 刚装好的系统，列出来的是哪些文件夹？

## 练习 3 · 敢乱试（3 分钟）
**放心，下面这些都不危险。** 试着敲：
```bash
ls ~            # 看看家目录（你个人的地盘）里有什么
ls /            # 看看系统根目录（系统的「最顶层」）
pwd             # 你刚到 / 了吗？再敲 pwd 看路径变没变
```
> 小发现：在 `/` 里敲 `pwd`，会看到路径变了。`/` 和 `~` 这些都是**路径**，你正在学会它们。

## 练习 4 · 拍快照（2 分钟）
在虚拟机软件菜单里找到「快照」，拍一张，命名为「Day1 起步」。今天之后，它就给你兜底。
