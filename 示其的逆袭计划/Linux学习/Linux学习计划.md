# Linux 学习计划（20 天 · 面向 AI 方向 + 网安兴趣）

示其的 Linux 学习路线 —— 从零基础到能用命令行跑 Python / 部署服务，为跨考浙大计算机学硕补上系统基础。

你是数学专业，目标是计算机 AI 方向，最近对网安感兴趣。Linux 是这两条线共同的**地基**：

- **AI 方向**：几乎所有深度学习训练/推理服务器都是 Linux；显卡驱动、CUDA、Docker 容器、云服务器全是命令行生态。不会 Linux 谈不上部署模型。
- **网安方向**：Kali Linux 就是渗透测试的标准平台；nmap / sqlmap / metasploit / wireshark 这些核心工具几乎全是 Linux 命令行。想玩网安，命令行是基本功。
- **数学 → 计算机**：数学训练抽象与严格推理，计算机要求理解"东西怎么在机器上跑"。Linux 是唯一开放、透明、能真正看穿的系统。

> 一句话：学 Linux，等于同时给「AI」和「网安」两块地基打桩。

---

## 学习方法（沿用 Python 的习惯）

- 每天只深入一块，配「知识点.md」+「练习.md」两个文件
- 练习 = 在虚拟机里亲手敲命令，多敲才记得住；命令行不怕犯错，怕不敢试
- 动手前先给虚拟机拍**快照**，搞坏了一键还原
- 不图快，稳扎稳打
