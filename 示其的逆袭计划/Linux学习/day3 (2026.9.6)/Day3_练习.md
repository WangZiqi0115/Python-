# Day 3 · 练习 (2026.9.6)
====================================
今天主题：文件与目录操作。在 Ubuntu 终端里照敲，重点观察两件事：
- **cp 之后**：原文件还在不在？（在）
- **mv 之后**：原文件去哪了？（被搬走了，原处没了）

动手前先给你的虚拟机拍个快照——万一 `rm` 手滑还能还原。

## 练习 1 · 建目录树（2 分钟）
```bash
cd ~
mkdir -p 我的项目/作业/数学
ls 我的项目
```
> 思考：`-p` 让「作业」「数学」一次建好。`ls 我的项目` 应该看到「作业」。

## 练习 2 · 建文件 + 复制（3 分钟）
```bash
cd ~/我的项目
touch 笔记.txt
ls
cp 笔记.txt 笔记_副本.txt
ls                      # 现在有两个文件
```
> 思考：cp 之后，原文件「笔记.txt」还在不在？（在——cp 是复制不是移动）。

## 练习 3 · 重命名 + 移动（4 分钟）
```bash
mv 笔记_副本.txt 数学笔记.txt
mv 数学笔记.txt 作业/
ls 作业                  # 数学笔记.txt 应该进来了
ls                      # 当前目录里还有 数学笔记.txt 吗？（没了）
```
> 思考：mv 到「作业/」（已存在目录）= 移动；如果目标是「新名字」= 重命名。这两个区别你分清了吗？

## 练习 4 · 删除（3 分钟，小心！）
```bash
cd ~/我的项目
ls                       # 先看清楚有什么
rm 笔记.txt              # 删一个文件
rm -r 作业/             # 删目录要加 -r
ls
```
> ⚠️ 提示：先 `cd` 到对的地方、`ls` 看一眼再删。终端里删掉就真没了。

## 练习 5 · 通配符（3 分钟）
```bash
cd ~/我的项目
touch a.txt b.txt a1.txt a2.txt    # 造四个文件
ls *.txt                           # 所有 txt（四个都在）
ls a?.txt                          # 只有 a1.txt a2.txt（? 占一个字符）
ls [ab].txt                        # 只有 a.txt b.txt（[ab] 是 a 或 b 一个字符）
rm a?.txt                          # 删掉 a1.txt a2.txt
ls                                 # 剩下 a.txt b.txt
```
> 思考：`*` `?` `[]` 的区别？为什么 `a?.txt` 能匹配 a1/a2 但不匹配 `b.txt`？
