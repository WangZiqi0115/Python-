# Day 3 · 文件与目录操作（mkdir / touch / cp / mv / rm / 通配符）(2026.9.6)
====================================================
今天搞懂六件事：
1. 怎么**创建**目录和文件（mkdir / touch）
2. 怎么**复制**（cp）
3. 怎么**移动 / 重命名**（mv）
4. 怎么**删除**（rm）—— 附一个超重要的警告
5. 用**通配符**（ `*` `?` `[]` ）一把抓一片文件
6. 继续用昨天学的**绝对 / 相对路径**来干活

先回顾一句话：昨天你学会了在「文件树」上**找路、移动**；今天你要学会在这棵树上**增、删、搬东西**。命令还是那套逻辑——「动词 + 对象」，只是今天动词多了几个。


# 一、创建：mkdir（造目录）和 touch（造文件）

## mkdir —— make directory，新建文件夹
```bash
mkdir 笔记                # 在当前目录下建一个叫「笔记」的文件夹
mkdir -p 项目/数据/图片    # -p = parents，一次建多级（缺的自动补）
```
**解析**：`mkdir ①目录名`。想一次建一整串嵌套目录，加 `-p`（parent），它会自动把中间缺的「项目」「数据」一起建好，不用一级一级敲。

## touch —— 新建空文件（或刷新时间戳）
```bash
touch 说明.txt          # 建一个空的「说明.txt」
touch a.txt b.txt       # 一次建多个文件
```
**注意**：`mkdir` 造的是**目录**，`touch` 造的是**文件**——这俩别搞混。`touch` 出来的文件是空的（0 字节）。


# 二、复制与移动：cp 和 mv

## cp —— copy，复制一份（原文件还在）
```bash
cp 说明.txt 说明_备份.txt     # 把 说明.txt 复制成 说明_备份.txt（两个都在）
cp 说明.txt 笔记/             # 复制进「笔记」文件夹里（名字不变）
cp -r 项目/ 备份/            # -r = recursive，复制「目录」必须加 -r（递归）
```
**解析**：`cp ①源 ②目标`。复制**文件**直接 `cp`；复制**目录**必须加 `-r`（递归，把里面东西一起拷）。类比：cp = 复印一份，**原件留着**。

## mv —— move，移动 或 重命名（原位置没了）
这是**同一件事**，两个用途：
```bash
mv 说明.txt 笔记/说明.txt   # 「移动」：把 说明.txt 挪进 笔记/（原处没了）
mv 说明.txt 重点.txt        # 「重命名」：把 说明.txt 改名叫 重点.txt
mv 重点.txt 笔记/           # 又能移动又能改名，一个命令都能干
```
**关键一眼判断：** `mv ①源 ②目标`，看**目标**是什么：
- 目标是个**已存在的目录** → 就是「移动」（把它挪进去）
- 目标是个**不存在的名字** → 就是「重命名」

> 给数学系的类比（可跳过）：`cp` 像「深拷贝」，复制一份完整数据；`mv` 更像「改指针」，只改「这个名字指向哪个位置」，不复制数据，所以快。


# 三、删除：rm —— 一个必须有警告的操作！

## rm —— remove，删除
```bash
rm 说明_备份.txt        # 删除一个文件
rm -r 备份/            # 删除「目录」要加 -r（递归删光里面）
rm -f 某文件           # -f = force，不提示直接删（慎用）
rm -rf 某目录/         # 最危险组合：-r 递归 + -f 强制，删谁谁没
```
**⚠️ 超重要警告：**
- **终端里删除 = 直接进黑洞，没有回收站！** 没有 Ctrl+Z 后悔，删错就是真没了。
- **`rm -rf` 是著名事故制造机**。网上流传的 `rm -rf /`、`sudo rm -rf /` 能直接把整个系统删光。**永远不要乱敲 `rm -rf`，尤其别对根目录 `/`、家目录 `~` 下手。**
- **防手滑三步**：先 `cd` 到对的地方 → `ls` 看清里面是什么 → 再删。绝不要一上来就 `rm -rf *`。


# 四、通配符（wildcard）：一把抓一片

昨天学了路径「暗号」`.` `..` `~`；今天学**文件名**的「暗号」——通配符，用来**批量匹配文件名**。和正则里的 `*` `.` `[]` 一个道理（数学系秒懂）。

| 通配符 | 匹配 | 例子 |
|--------|------|------|
| `*` | 任意**多个**字符（0 个也行） | `ls *.py` → 所有 .py 结尾的文件 |
| `?` | 恰好 **1** 个任意字符 | `ls a?.txt` → a1.txt、ab.txt（`?` 必须占 1 个字符）|
| `[abc]` | 括号里**任意一个**字符 | `ls [ab].txt` → a.txt 、b.txt |

**批量操作示例：**
```bash
ls *.py             # 列出所有 python 文件
cp *.py 备份/       # 把所有 .py 一次拷贝到 备份/
rm *.tmp            # 删掉所有 .tmp 临时文件（小心！先 ls 确认）
ls a?.txt           # 匹配 a1.txt、ab.txt，但不匹配 a.txt（? 必须占一个字符）
```
> 口诀：`*` 是「随便多少都行」，`?` 是「正好一个」，`[]` 是「**括号里几个中挑一个**——写几个都行，但**永远只占一个字符位置**」。

**`[]` 还能写范围、能取反（进阶，了解即可）：**
```bash
ls [0-9].txt     # 匹配 1.txt、5.txt……（0~9 一个数字 + .txt）
ls [a-c].txt     # 匹配 a.txt、b.txt、c.txt（a/b/c 之一）
ls [0-9a-z].txt  # 数字或小写字母之一
ls [!abc].txt    # 除了 a/b/c 之外的任意一个字符（! 取反）
```


# 五、今日小结 · 你已经会的事

1. `mkdir` 建目录、`touch` 建空文件（区分「目录」和「文件」）
2. `cp` 复制、`mv` 移动 / 重命名（看目标是「已存在目录」还是「新名字」）
3. `rm` 删除——牢记没有回收站、`rm -rf` 危险
4. `*` `?` `[]` 通配符批量匹配，配合 cp / mv / rm 一把抓
5. 全都能搭配**绝对 / 相对路径**，比如 `cp /home/shiq/图片/* ./`


# 六、例题精讲（先看懂，再动手）

### 例 1 · 一次建好一个项目目录树
- **题目**：在家目录下建 `myproject/src`、`myproject/data` 的目录结构。
- **思路**：多级目录用 `mkdir -p`。
- **参考代码：**
```bash
cd ~
mkdir -p myproject/src myproject/data
ls myproject
```
- **运行输出：**
```
src  data
```
- **关键点**：`-p` 一次建多级；`mkdir` 后跟多个目录名，就一次建好几个。

### 例 2 · 复制 + 重命名一个文件
- **题目**：把 `main.py` 复制一份改名为 `main_backup.py`，再把它移动进 `src/`。
- **思路**：`cp 源 新名字` 复制并改名；`mv 文件 目录/` 移动进去。
- **参考代码：**
```bash
touch main.py                 # 先建个空文件
cp main.py main_backup.py     # 复制并改名
mkdir src
mv main_backup.py src/        # 移进 src/
ls src
```
- **运行输出：**
```
main_backup.py
```
- **关键点**：`cp 源 新名字` = 复制并改名；`mv 文件 目录/` = 移动。注意 mv 之后，原目录里 `main_backup.py` 就没了（被搬走）。

### 例 3 · 用通配符批量管理文件
- **题目**：当前目录有一堆 `.png` 图和一撮 `.tmpp` 临时文件，列出所有 `.png`，再删掉所有 `.tmpp`。
- **思路**：`*.png` 匹配所有 png；`*.tmpp` 匹配临时文件。
- **参考代码：**
```bash
ls *.png        # 先看有什么 png
rm *.tmpp       # 删掉所有临时文件（先 ls 确认过再删！）
ls
```
- **运行输出：**
```
(列出的 .png 文件……)
(删掉后剩下的文件……)
```
- **关键点**：**永远先 `ls *.xxx` 看清匹配到哪些，再执行 `rm`**。这是防手滑的铁律。
