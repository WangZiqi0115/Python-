# Excel 第 2 课 · 常用快捷键与高效操作 (2026.8.9)

## 学习目标

今天学完后，你要能：

1. 用快捷键完成复制、剪切、粘贴、撤销、重做
2. 用 `F2` 编辑单元格、`F4` 切换绝对引用、`Alt+=` 自动求和
3. 快速选择、跳转、批量填充
4. 用 `Ctrl+Shift+L` 开关筛选
5. 用快捷键调换两行数据

---

## 一、编辑类快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+C` | 复制 |
| `Ctrl+X` | 剪切 |
| `Ctrl+V` | 粘贴 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |
| `F2` | 进入当前单元格编辑状态 |
| `Delete` | 清除选中单元格内容 |
| `Ctrl+Enter` | 把输入的内容同时填进所有选中的格子 |
| `Ctrl+D` | 向下填充上一格内容 |
| `Ctrl+R` | 向右填充左一格内容 |

## 二、选择与跳转快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+方向键` | 跳到当前数据区域的边缘 |
| `Ctrl+Shift+方向键` | 从当前格连续选中到数据边缘 |
| `Ctrl+A` | 选中当前数据区域 |
| `Ctrl+Home` | 跳到 A1 |
| `Ctrl+End` | 跳到数据区域的右下角 |
| `Shift+方向键` | 一格一格扩展选中范围 |

## 三、函数与公式快捷键

| 快捷键 | 作用 |
|--------|------|
| `Alt+=` | 自动求和 |
| `F4` | 在公式里循环切换绝对引用：`A1` → `$A$1` → `A$1` → `$A1` |
| `Ctrl+反引号` | 显示 / 隐藏公式 |
| `F9` | 手动重新计算 |

## 四、筛选与排序快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+Shift+L` | 开启 / 关闭筛选 |
| `Alt+↓` | 打开选中格所在列的筛选下拉菜单 |

## 五、日期和时间

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+;` | 插入当前日期 |
| `Ctrl+Shift+;` | 插入当前时间 |

## 六、调换两行数据

Excel 没有一键交换两行的按钮，最常用的组合是：

1. 点行号，选中整行。
2. 按 `Ctrl+X` 剪切。
3. 点目标行的任意单元格。
4. 按 `Ctrl+Shift+=`，选择“插入剪切单元格”。

例如把第 3 行和第 5 行互换：

- 先剪切第 3 行。
- 点第 5 行，按 `Ctrl+Shift+=`，把第 3 行插到第 5 行上面。
- 再剪切原来第 5 行的位置，插到第 3 行的原位置。

如果做乱了，按 `Ctrl+Z` 撤销重来。

## 七、今天的常见坑

1. `Ctrl+Enter` 批量填充前，必须先把所有目标格子选中。
2. `F4` 要在公式编辑状态下按，才会切换 `$`。
3. `Ctrl+Shift+L` 是筛选开关，按一次开、再按一次关。
4. `Alt+=` 要先点目标单元格，Excel 才会自动识别求和区域。
5. 调换整行时，剪切后必须选“插入剪切单元格”，不能直接粘贴，否则可能覆盖数据。
