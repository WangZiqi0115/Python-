# Excel 第 1 课 · 函数、排序筛选与图表 (2026.8.8)

## 学习目标

今天学完后，你要能独立完成：

1. 建一张带数据的表格
2. 用函数算总分、平均分、及格率
3. 用 IF / COUNTIF / SUMIF / VLOOKUP 处理数据
4. 排序、筛选数据
5. 插入一张能讲清楚的图表

---

## 一、认识 Excel 的基本结构

- 一个 Excel 文件叫**工作簿**，里面可以有多张**工作表**。
- 单元格地址由列字母和行数字组成，例如 `A1` 表示第 A 列第 1 行。
- 直接输入文字或数字是普通数据；输入内容以 `=` 开头才是公式。
- 写完公式后按 Enter 计算，公式会显示结果。

## 二、相对引用和绝对引用

这是 Excel 最容易卡住的地方，但理解后很简单。

**相对引用**

公式 `=B2*C2` 填在 D2，向下填充时 Excel 会自动变成：

```text
=B3*C3
=B4*C4
=B5*C5
```

**绝对引用**

公式 `=$B$2*C2` 中，`$B$2` 被锁死，向下填充时不会变：

```text
=$B$2*C3
=$B$2*C4
```

什么时候用绝对引用？当某个值固定不变时，比如折扣率、税率、商品单价。

记忆方法：**`$` 锁住谁，谁就不变。**

## 三、常用函数

| 函数 | 作用 | 示例 |
|------|------|------|
| `SUM` | 求和 | `=SUM(C2:C11)` |
| `AVERAGE` | 求平均 | `=AVERAGE(C2:C11)` |
| `MAX` / `MIN` | 最大值 / 最小值 | `=MAX(C2:C11)` |
| `COUNT` | 统计数字个数 | `=COUNT(C2:C11)` |
| `COUNTA` | 统计非空单元格个数 | `=COUNTA(B2:B11)` |
| `IF` | 条件判断 | `=IF(C2>=60,"及格","不及格")` |
| `COUNTIF` | 按条件计数 | `=COUNTIF(C2:C11,">=60")` |
| `SUMIF` | 按条件求和 | `=SUMIF(B2:B11,"男生",C2:C11)` |
| `VLOOKUP` | 按值查找 | `=VLOOKUP("001",A2:E11,2,FALSE)` |

重点理解：

- `IF` 返回的是你写在引号里的文字，不是数字。
- `COUNTIF` 和 `SUMIF` 的格式都是 `区域, 条件`，条件里比较符号要加引号。
- `VLOOKUP(查什么, 在哪查, 返回第几列, 是否精确)`，前三个最常用。
- `VLOOKUP` 要求**查询值必须在查找区域的第一列**。

## 四、排序和筛选

- 排序：选中整个数据区域，点“数据 → 排序”，选择关键字和升降序。
- 筛选：选中表头，点“数据 → 筛选”，每列会出现下拉箭头。
- 注意：不要只选中一列再排序，否则数据会错位。
- 筛选状态下的数据可以复制出来，但注意行号可能不连续。

## 五、图表

插入图表前，先选中“表头 + 数据区域”，再点“插入 → 图表”。

- 柱状图：适合比较大小。
- 折线图：适合看趋势。
- 饼图：适合看占比。

图表做好后必须检查三件事：

1. 标题能不能看懂
2. 横轴、纵轴表示什么
3. 数据标签有没有显示

## 六、今天的常见坑

1. 公式里用了中文引号，例如 `=IF(C2>=60,"及格")` 里的中文引号会报错。
2. 函数括号没配对，比如 `=SUM(C2:C11` 少了一个右括号。
3. `VLOOKUP` 查询值不在查找区域第一列。
4. 排序时只选了一列，导致整行数据错位。
5. 图表没有标题，别人看不懂在比较什么。
