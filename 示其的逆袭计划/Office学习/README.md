# Office 办公软件学习

利用空闲时间学习 Word / Excel / PPT 的实用操作，目标是服务数模论文、课程报告和项目汇报。

## 学习顺序

1. **Excel**：常用函数、排序筛选、条件格式、图表、数据透视表
2. **Word**：样式、多级标题、自动目录、页眉页脚、分节符
3. **PPT**：母版、版式、图文排版、动画与切换

## 练习任务

- Excel：把自己 Python 练习里的成绩数据导入，统计最高分、平均分、按条件筛选并画图
- Word：把 Python 学习日志排版成一份带封面、目录、页码的正式报告
- PPT：把 Day 12 通讯录项目做成 1 页项目介绍，讲清楚做了什么、怎么实现、遇到什么问题
